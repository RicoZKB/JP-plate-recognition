# ナンバープレート検出システム

**神戸電子専門学校様 向け**

AI搭載リアルタイムナンバープレート検出・認識システム

---

## システム概要

本システムは、NVIDIA Jetson Nanoを使用した日本のナンバープレート自動認識システムです。
駐車場の入退場管理、車両追跡などの用途にご利用いただけます。

### 主な機能

✅ **リアルタイム検出**: 15〜25 FPSで高速処理
✅ **日本語対応**: 日本のナンバープレート完全対応（地域名、分類番号、ひらがな、指定番号）
✅ **入退場管理**: 入場・退場イベントの切り替え可能
✅ **デジタルズーム**: 2〜20メートルの距離に対応
✅ **自動ログ記録**: CSV形式で日次ログ自動保存
✅ **ビデオ録画**: 検出結果付きビデオの自動録画

## ⚡ クイックスタート

```bash

cd /home/jetson/yolo/yolov7/Licence-Plate-Detection-Recognition-Recording

# 2. システムを起動
```

## 🔧 基本設定

### 入場・退場の切り替え

**ファイル**: `fr01.py` の25行目

```python
# 入場イベントの場合
EVENT_DIRECTION = "in"

# 退場イベントの場合
EVENT_DIRECTION = "out"
```

### ズーム倍率の調整

**ファイル**: `fr01.py` の64行目

```python
FIXED_ZOOM = 2.4  # 推奨値: 2.0〜3.5
```

詳しくは「クイックスタートガイド.md」をご覧ください。
