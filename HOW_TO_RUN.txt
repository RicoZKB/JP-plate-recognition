================================================================================

Step 2: Activate virtual environment
    source ../myenv/bin/activate

Step 3: Set GPU workaround
    export LD_PRELOAD=/usr/lib/aarch64-linux-gnu/libGLdispatch.so.0

Step 4: Run the program
    python3 inout_event.py

Step 5: When done, deactivate

================================================================================
⚙️ CHANGE SETTINGS:
================================================================================

To change video source or mode:

1. Edit the main file:
   nano inout_event.py

2. Find lines 32-44:

   USE_CAMERA = False   # Change to True for CSI camera
   USE_FILE = True      # Change to False if using camera
   USE_YOUTUBE = False  # Change to True for YouTube stream

   INPUT_VIDEO_PATH = "input_videos/Trim03.mp4"  # Change video file

   DIRECTION_MODE = "IN_ONLY"  # Options: IN_ONLY, OUT_ONLY, BIDIRECTIONAL

3. Save and exit:
   Ctrl + X, then Y, then Enter


================================================================================
🐛 TROUBLESHOOTING:
================================================================================

Problem: "Permission denied"
Solution:
    chmod +x easy_run.sh

Problem: "No such file or directory"
Solution:
    Check you're in the right directory:
    pwd

    Should show:
    /home/jetson/yolo/yolov7/Licence-Plate-Detection-Recognition-Recording

Problem: "Module not found"
Solution:
    Make sure virtual environment is activated:
    source ../myenv/bin/activate

Problem: Camera not found
Solution:
    Edit inout_event.py:
    USE_CAMERA = False
    USE_FILE = True
